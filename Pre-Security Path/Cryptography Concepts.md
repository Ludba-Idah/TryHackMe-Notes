# Room: Cryptography Concepts

**Category:** Fundamentals

## Overview
This room covers the fundamentals of securing data, exploring the differences between symmetric encryption, asymmetric encryption, and cryptographic hashing.

## Key Takeaways
* **Symmetric vs Asymmetric:** Symmetric encryption uses one shared key to both encrypt and decrypt data. Asymmetric uses a pair of keys: a public key to encrypt and a private key to decrypt.
* **What Does Cryptography Achieve:** It protects confidentiality and integrity, and it's the backbone of almost every secure system you use online.
* **Encryption:** Encryption secures data and requires a key to reverse.
