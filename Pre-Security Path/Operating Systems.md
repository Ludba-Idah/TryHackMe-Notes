# Room: Operating Systems

**Category:** Fundamentals


## Overview
This room covers what an operating system is, explores on the different user interfaces and tells us about the many types of
operating systems with examples. This room also covers on the different system privilage layers.

## Key Takeaways
* **What is an OS:** Software that acts as an interface between user applications and system hardware to manage RAM, CPU, and storage.
* **Privilege Layers:** Systems split execution into User Mode (restricted access to prevent crashes) and Kernel/Root Mode (unrestricted access reserved for core hardware operations).
* **Key Gotcha:** Daily tasks should always be done on a standard user account—running everything as Root/Admin leaves the entire system vulnerable to accidental damage or malware.
