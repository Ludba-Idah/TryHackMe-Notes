# Room: Cyber Chef Basics

**Category:** Fundamentals
## Overview
This room tells us how to use CyberChef, which is a great tool for encryption, encoding, compression and data analysis.

## Key Takeaways

4 Areas
* **Operations ->** This is a practical and comprehensive repository of all the diverse operations that CyberChef is equipped                      to perform. 
* **Recipe ->** This is where you take control, defining each operation's arguments and options precisely and purposefully.
* **Input ->** The input area provides a user-friendly space where you can easily input text or files by pasting, typing, or                  dragging them to perform operations.
* **Output ->** The output area is a visual space that showcases the data processing results.
