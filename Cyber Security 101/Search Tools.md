# Room: Search Tools

**Category:** Windows

## Overview
This room covers techniques for searching text, filtering logs, and using targeted web search operators to find specific files and security information quickly.

## Core Commands & Syntax
* `findstr "pattern" filename.txt` -> Searches for a specific string of text inside files on Windows (`/i` flag ignores case).
* `grep "pattern" filename.txt` -> Filters lines matching a specific pattern inside files on Linux/WSL (`-i` ignores case).
