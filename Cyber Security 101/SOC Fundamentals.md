# Room: SOC Fundamentals

**Category:** Fundamentals

## Overview
This room covers the fundamentals of the Security Operations Center (SOC), and talks about the 3 pillars of the SOC.

## Key Takeaways

SOC Focus
* **SOC Focus ->** The main focus of the SOC is detection and response, detection meaning detecting vulnarebilities and unauthorised activity, while resopone minimizes and deefines the root cause of the impact.

3 Pillars of The SOC
* **People ->**The People are known as the SOC team. They have the following roles: SOC Analyst (Level 1-3), security engineer, detection engineer and SOC manager.
* **Process ->**Each role has its own processes in a SOC team. Example: The role of Level 1 SOC Analysts as the first responders to carry out alert triage and determine if it is harmful. 
* **Technology ->**The Technology portion in the SOC pillars refers to the security solutions. These security solutions efficiently minimize the SOC team's manual effort to detect and respond to threats.
