# Room: OWASP Top 10 2025: Application Design Flaws

**Category:** Application Architecture & Design Security

## Overview
This room breaks each 4 of the OWASP Top 10 2025 categories. In this room, we learn about the categories that are related to failures in architecture and system design.

## Key Takeaways
* **AS02: Security Misconfigurations:** It occurs when applications are deployed with unsafe defaults, incomplete settings, or exposed services. It requires hardening and automated reviews to prevent.
* **AS03: Software Supply Chain Failures:** It happens from relying on unverified or outdated third-party packages or pipelines which can compromise the entire infrastructure.
* **AS04: Cryptographic Failures:** It involves failing to secure data or using legacy ciphers instead of secure KMS platforms.
* **AS06: Insecure Design:** It represents flawed foundational logic and trust boundaries skipped during threat modeling.
