# Room: Windows Fundamentals 1 & 2

**Category:** Windows

## Overview
These rooms cover the core architecture of the Windows operating system, including the NTFS file system and the User Account Control (UAC).

## Core Commands & Syntax
* `lusrmgr.msc` -> Opens Local Users and Groups to quickly manage user accounts, passwords, and permission groups.
* `msconfig` -> It opens System Configuration to troubleshoot the Windows boot process, safe mode, and manage background services.
* `taskschd.msc` -> It opens Task Scheduler to view or automate scripts and programs.
* `regedit` -> It opens the Registry Editor to view or modify core Windows system and application settings.
